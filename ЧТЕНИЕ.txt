================================================================================
              ЧТО ДЕЛАТЬ ЕСЛИ УСТАНОВЩИК СРАЗУ ЗАВЕРШАЕТСЯ
================================================================================

ПРОБЛЕМА: Установщик открывается и сразу закрывается.

РЕШЕНИЕ:

1. Проверьте, что Node.js установлен:
   - Откройте командную строку (cmd)
   - Введите: node --version
   - Если версия не показана - установите Node.js с https://nodejs.org/

2. Запустите установщик через консоль:

   cd C:\Users\Денис\Desktop\kdz
   node installer\setup.js

3. Если ошибка с зависимостями:

   cd C:\Users\Денис\Desktop\kdz\installer
   npm install

   Затем снова:

   cd C:\Users\Денис\Desktop\kdz
   node installer\setup.js

                    КАКИЕ ФАЙЛЫ НУЖНЫ ДЛЯ ЗАПУСКА

   ┌──────────────────────────┐

   └──────────────────────────┘

================================================================================
                          ПОРЯДОК ДЕЙСТВИЙ
================================================================================

1. СКОПИРУЙТЕ папку kdz на СЕРВЕР 1

2. ЗАПУСТИТЕ "Установить сервер.bat"
   - Выберите "Сервер 1"
   - Введите параметры PostgreSQL
   - Дождитесь завершения

3. ЗАПУСТИТЕ "Start Server 1.bat"
   - Сервер запустится
   - Откройте http://localhost:3001

4. СКОПИРУЙТЕ папку kdz на СЕРВЕР 2

5. ЗАПУСТИТЕ "Установить сервер.bat"
   - Выберите "Сервер 2"
   - Введите параметры PostgreSQL
   - Дождитесь завершения

6. ЗАПУСТИТЕ "Start Server 2.bat"
   - Сервер запустится
   - Откройте http://localhost:3002/admin
   - Логин: admin (или ваш), Пароль: заданный вами

================================================================================
                          ПРОВЕРКА РАБОТЫ
================================================================================

СЕРВЕР 1:
- Откройте http://localhost:3001
- Создайте заявку с файлами
- Дождитесь синхронизации по расписанию; при необходимости смотрите консоль Server 1 или таблицу sync_logs в БД

СЕРВЕР 2:
- Откройте http://localhost:3002/admin
- Войдите (admin / ваш пароль)
- Проверьте заявку (после синхронизации)

================================================================================
                          УСТРАНЕНИЕ ПРОБЛЕМ
================================================================================

Ошибка: "Node.js not found"
→ Установите Node.js с https://nodejs.org/

Ошибка: "npm not found"
→ Node.js установлен, но не в PATH. Перезапустите консоль.

Ошибка: "Cannot find module 'inquirer'"
→ cd installer
→ npm install

Ошибка: "Port already in use"
→ Измените PORT в .env файле

Ошибка: "PostgreSQL connection failed"
→ Проверьте логин/пароль в настройках БД
→ Убедитесь, что PostgreSQL запущен

Ошибка синхронизации
→ Проверьте, что SYNC_SECRET одинаковый на обоих серверах (мин. 16 символов)
→ Проверьте, что SERVER2_URL на Сервере 1 указывает на правильный адрес Сервера 2
→ Смотрите консоль Server 1 и таблицу sync_logs в БД
