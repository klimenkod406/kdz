================================================================================
              СИСТЕМА ЗАЯВОК - КРАТКАЯ ИНСТРУКЦИЯ ПО УСТАНОВКЕ
================================================================================

1. СКОПИРУЙТЕ ПАПКУ ПРОЕКТА НА КАЖДЫЙ СЕРВЕР
   - На первый сервер (прием заявок)
   - На второй сервер (хранение + админ-панель)

2. ЗАПУСТИТЕ УСТАНОВЩИК НА КАЖДОМ СЕРВЕРЕ
   - Дважды кликните на "Установить сервер.bat"
   - Или выполните: node installer/setup.js

3. СЛЕДУЙТЕ ИНСТРУКЦИЯМ УСТАНОВЩИКА:

   Для Сервера 1 (прием заявок):
   - Выберите: "Сервер 1 - Прием заявок"
   - Введите параметры PostgreSQL
   - Введите URL Сервера 2 (например: http://192.168.1.100:3002)
   - Настройте порт (по умолчанию 3001)

   Для Сервера 2 (хранение + админка):
   - Выберите: "Сервер 2 - Хранение и админ-панель"
   - Введите параметры PostgreSQL
   - Задайте логин/пароль администратора
   - Настройте порт (по умолчанию 3002)

4. ПОСЛЕ УСТАНОВКИ:
   - Установщик автоматически запустит сервер
   - В папке останется только необходимое для этого сервера

5. ДОСТУП В ЛОКАЛЬНОЙ СЕТИ:

   Сервер 1 (форма заявок):
   http://<IP-адрес-сервера-1>:3001

   Сервер 2 (админ-панель):
   http://<IP-адрес-сервера-2>:3002
   Логин: admin (или заданный вами)
   Пароль: заданный вами (не выводится в консоль)

================================================================================
                           ЯРЛЫКИ ДЛЯ ЗАПУСКА
================================================================================

Установить сервер.bat    - Запуск установщика
Start Server 1.bat       - Запуск сервера заявок (после установки)
Start Server 2.bat       - Запуск админ-панели (после установки)

================================================================================
                         ВАЖНО ДЛЯ СВЯЗИ СЕРВЕРОВ
================================================================================

На Сервере 1 при установке укажите корректный URL Сервера 2:
- Если серверы в одной сети: http://<IP-сервера-2>:3002
- Если на одном компьютере: http://localhost:3002

Сервер 1 будет автоматически отправлять заявки на Сервер 2
каждые 5 минут (настраивается).

================================================================================
                              ОТКРЫТЬ ПОРТЫ
================================================================================

Если не работает доступ из сети, откройте порты в фаерволе:

Windows (PowerShell от администратора):
New-NetFirewallRule -DisplayName "Ticket Server 1" -Direction Inbound -LocalPort 3001 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "Ticket Server 2" -Direction Inbound -LocalPort 3002 -Protocol TCP -Action Allow
