ПОЧЕМУ ВОЗНИКАЕТ ОШИБКА "Cannot find module 'inquirer'"?

При скачивании с GitHub папки node_modules НЕТ в архиве.
Она добавляется в .gitignore и не загружается в репозиторий.

================================================================================
                            РЕШЕНИЕ
================================================================================

СПОСОБ 1: Автоматическая установка (Windows)

1. Дважды кликните на "install-dependencies.bat"
2. Дождитесь завершения установки
3. Запустите "Установить сервер.bat"

СПОСОБ 2: Ручная установка (Любая ОС)

1. Откройте консоль в папке проекта
2. Выполните:
   
   cd installer
   npm install
   cd ..

3. Запустите установщик:
   
   node installer\setup.js

================================================================================
                    ПОШАГОВАЯ ИНСТРУКЦИЯ
================================================================================

ШАГ 1: Скачайте репозиторий
   - GitHub: Download ZIP
   - Или: git clone <url>

ШАГ 2: Распакуйте (если ZIP)
   - Извлеките в папку, например: C:\kdz

ШАГ 3: Откройте консоль
   - Win + R → cmd
   - cd C:\kdz

ШАГ 4: Проверьте Node.js
   node --version
   (должна быть 16+)

ШАГ 5: Установите зависимости
   cd installer
   npm install
   
   (займёт 1-2 минуты)

ШАГ 6: Запустите установщик
   cd ..
   node installer\setup.js

ШАГ 7: Следуйте инструкциям установщика

================================================================================
                    ЧАСТЫЕ ОШИБКИ
================================================================================

Ошибка: "Cannot find module 'inquirer'"
Решение: cd installer && npm install

Ошибка: "npm not found"
Решение: Установите Node.js с https://nodejs.org/

Ошибка: "Node.js not found"
Решение: Установите Node.js с https://nodejs.org/

Ошибка: "EPERM: operation not permitted"
Решение: Запустите консоль от имени администратора

Ошибка: "network timeout"
Решение: Проверьте интернет-соединение, повторите npm install
