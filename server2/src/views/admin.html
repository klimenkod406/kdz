⚠️ Очистить базу данных

Внимание! Это действие удалит все заявки, комментарии, историю и вложения.

Будут очищены следующие таблицы:

  • Заявки (tickets)
  • Вложения (ticket_attachments)
  • Комментарии (ticket_comments)
  • История изменений (ticket_history)
  • Логи синхронизации (sync_logs)
  • Сессии (session)

Это действие нельзя отменить!

📤 Восстановить базу данных

Восстановление БД
Выберите JSON или SQL файл, который был ранее выгружен через функцию "Выгрузить БД".

Поддерживаемые форматы: .json (для чтения), .sql (для бэкапа)

Важно: Текущие данные будут заменены данными из файла. Таблица администраторов не будет затронута.
