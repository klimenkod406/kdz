│  НА СЕРВЕРЕ 1 (Прием заявок):                                            │
│                                                                          │
│  1. Установить сервер.bat    → Запустить 1 раз при установке            │
│  2. Start Server 1.bat       → Запускать для старта сервера             │
│                                                                          │

│  2. Start Server 2.bat       → Запускать для старта сервера             │
│                                                                          │

└──────────────────────────────────────────────────────────────────────────┘

================================================================================
                         ИНСТРУКЦИЯ ПО УСТАНОВКЕ
================================================================================

1. СКОПИРУЙТЕ папку проекта на сервер

2. ЗАПУСТИТЕ "Установить сервер.bat"
   - Выберите тип сервера (1 или 2)
   - Введите параметры PostgreSQL
   - Дождитесь завершения

3. ЗАПУСТИТЕ соответствующий Start Server *.bat
   - Server 1: http://localhost:3001
   - Server 2: http://localhost:3002/admin (admin/admin123)

================================================================================
                              ВАЖНО!
================================================================================

❌ НЕ НУЖНЫ все 4 .bat файла одновременно!

После установки на каждом сервере остаётся:
  ✓ 1 файл для запуска (Start Server 1.bat или Start Server 2.bat)
  ✓ Папка с сервером (server1/ или server2/)
  ✓ Папки shared/ и installer/
