## 📊 Как работает удаление

### Логика:

```
1. Синхронизация прошла успешно
   ↓
2. Заявки помечены как отправленные (sent_to_server2 = TRUE)
   ↓
3. Запускается очистка старых заявок
   ↓
4. Удаляются заявки старше 7 дней
   ↓
5. Выводится сообщение об удалении
```

## ⚠️ Важные замечания

### 1. Удаление только после успешной синхронизации

Заявки удаляются только если:
- ✅ Синхронизация прошла успешно
- ✅ Заявка помечена как отправленная
- ✅ Прошло 7 дней с момента отправки

### 2. Данные на Server 2 не удаляются

Удаление происходит **только на Server 1**!

На Server 2 заявки хранятся постоянно.

### 3. Вложения удаляются автоматически

При удалении заявки её вложения удаляются **каскадом** (благодаря `ON DELETE CASCADE` в БД).
