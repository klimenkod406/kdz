PROBLEM: "Cannot find module 'inquirer'"

CAUSE: node_modules folder is NOT in GitHub (listed in .gitignore).

================================================================================
                            SOLUTION (2 STEPS)
================================================================================

Step 1: Install Dependencies

Windows:
  Double-click: install-dependencies.bat

Any OS:
  cd installer
  npm install
  cd ..

Step 2: Run Installer

Windows:
  Double-click: Установить сервер.bat

Any OS:
  node installer/setup.js

================================================================================
                    FULL INSTRUCTIONS
================================================================================

1. Download repository from GitHub
2. Extract to folder (e.g., C:\kdz)
3. Run install-dependencies.bat (or npm install in installer/)
4. Wait for installation to complete
5. Run Установить сервер.bat (or node installer/setup.js)
6. Follow installer instructions

================================================================================
                    CHECK BEFORE RUNNING
================================================================================

Node.js installed:
  node --version
  (should show v16.x.x or higher)

npm works:
  npm --version
  (should show version)

================================================================================
                    TROUBLESHOOTING
================================================================================

Error: "Cannot find module 'inquirer'"
Solution: cd installer && npm install

Error: "npm not found"
Solution: Install Node.js from https://nodejs.org/

Error: "Node.js not found"
Solution: Install Node.js from https://nodejs.org/

Error: "EPERM: operation not permitted"
Solution: Run console as Administrator

Error: "network timeout"
Solution: Check internet connection, retry npm install
