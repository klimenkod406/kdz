## 🚀 Быстрый старт

### 1. Запуск установщика

**Windows:**
- Дважды кликните на `Установить сервер.bat`

**Linux/Mac:**
```bash
node installer/setup.js
```

### 2. Выберите тип сервера

```
? Выберите тип сервера: (Use arrow keys)
> 📥 Сервер 1 - Прием заявок (временное хранение)
  💾 Сервер 2 - Хранение и админ-панель
```

### 3. Введите параметры PostgreSQL

```
Хост PostgreSQL: localhost
Порт PostgreSQL: 5432
Пользователь PostgreSQL: postgres
Пароль PostgreSQL: ********
Имя базы данных: tickets_temp (или tickets_permanent)
```

### 4. Настройте сервер

**Для Server 1:**
```
URL Сервера 2: http://192.168.1.100:3002
Интервал синхронизации: 5
Время хранения до отправки: 30
```

**Для Server 2:**
```
Секрет сессий: (автогенерация)
Логин администратора: admin
Пароль администратора: admin123
```

### 5. Сетевые настройки

```
Хост для прослушивания: 0.0.0.0
Порт сервера: 3001 (или 3002)
```

## 🔧 Что делает установщик

### 1. Очистка ненужных файлов

**Для Server 1:**
```
Удаляет: server2/
Остаётся: server1/, shared/, installer/
```

**Для Server 2:**
```
Удаляет: server1/
Остаётся: server2/, shared/, installer/
```

### 2. Установка зависимостей

**Server 1:**
```bash
npm install
✓ express
✓ pg
✓ multer
✓ axios
✓ form-data
✓ node-cron
✓ dotenv
✓ cors
```

**Server 2:**
```bash
npm install
✓ express
✓ pg
✓ multer
✓ bcrypt
✓ express-session
✓ connect-pg-simple
✓ dotenv
✓ cors
```

### 3. Создание базы данных

```sql
CREATE DATABASE tickets_temp;     -- Server 1
CREATE DATABASE tickets_permanent; -- Server 2
```

### 4. Выполнение миграций

**Server 1:**
- `tickets` - заявки
- `ticket_attachments` - вложения
- `sync_logs` - логи синхронизации

**Server 2:**
- `session` - сессии
- `admins` - администраторы
- `tickets` - заявки
- `ticket_attachments` - вложения
- `ticket_comments` - комментарии
- `ticket_history` - история изменений

### 5. Создание .env файла

**Server 1 (.env):**
```env
HOST=0.0.0.0
PORT=3001
DB_HOST=localhost
DB_PORT=5432
DB_NAME=tickets_temp
DB_USER=postgres
DB_PASSWORD=********
SERVER2_URL=http://localhost:3002
SYNC_INTERVAL_MINUTES=5
TEMP_STORAGE_MINUTES=30
```

**Server 2 (.env):**
```env
HOST=0.0.0.0
PORT=3002
DB_HOST=localhost
DB_PORT=5432
DB_NAME=tickets_permanent
DB_USER=postgres
DB_PASSWORD=********
SESSION_SECRET=auto_generated_secret
ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin123
```

### 6. Запуск сервера

После успешной установки сервер запускается автоматически.

## ⚠️ Возможные ошибки

### 1. Не удалось подключиться к PostgreSQL

```
✗ Ошибка подключения: password authentication failed for user "postgres"
```

**Решение:**
- Проверьте пароль PostgreSQL
- Убедитесь, что PostgreSQL запущен

### 2. Порт занят

```
Error: listen EADDRINUSE: address already in use :::3001
```

**Решение:**
- Измените порт в настройках
- Или остановите сервис, использующий порт

### 3. Ошибка npm install

```
npm install exited with code 1
```

**Решение:**
```bash
cd server1  # или server2
npm install
```

### 4. Не найдена папка server1/server2

```
[ERROR] Папка server1 не найдена!
```

**Причина:** Установщик уже запускался и удалил лишние папки.

**Решение:** Запустите установщик заново на чистую копию проекта.
