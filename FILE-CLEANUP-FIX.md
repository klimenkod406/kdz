# Удаление файлов после синхронизации

## ✅ Проблема исправлена

### 🔍 Что было не так:

**Файлы не удалялись с Сервера 1 после успешной отправки на Сервер 2.**

```
10:00 - Создана заявка с фото
10:01 - Синхронизация
        ✓ Заявка отправлена на Server 2
        ❌ Файлы остались на Server 1
```

---

### ✅ Что исправлено:

**Добавлено удаление файлов сразу после успешной синхронизации:**

```javascript
// После успешной отправки заявки
await TicketModel.markAsSent(ticket.id);

// Удаляем файлы
if (attachments.length > 0) {
  for (const attachment of attachments) {
    const filePath = path.join(UPLOAD_DIR, attachment.file_name);
    if (fs.existsSync(filePath)) {
      fs.unlinkSync(filePath);  // Физическое удаление
      console.log(`🗑️ Файл удалён: ${attachment.file_original_name}`);
    }
  }
  // Удаляем записи из БД
  await TicketModel.deleteAttachments(ticket.id);
}
```

## 💾 Что удаляется:

### 1. **Физические файлы**
```javascript
fs.unlinkSync(filePath);  // Удаляет файл с диска
```

### 2. **Записи в базе данных**
```javascript
await TicketModel.deleteAttachments(ticket.id);  // Удаляет записи из БД
```

---

## 🔒 Безопасность:

### ✅ Файлы удаляются ТОЛЬКО после:
1. Успешной отправки на Server 2
2. Пометки заявки как отправленной
3. Подтверждения от Server 2

### ❌ Файлы НЕ удаляются если:
1. Ошибка сети при отправке
2. Server 2 вернул ошибку
3. Файл не найден на диске
