# ⚠️ ПЕРВЫЙ ЗАПУСК ПОСЛЕ СКАЧИВАНИЯ С GITHUB

## Проблема

```
Error: Cannot find module 'inquirer'
```

**Причина:** Папка `node_modules` не загружается в GitHub (указана в `.gitignore`).

---

## ✅ Решение (2 шага)

### Шаг 1: Установите зависимости

**Windows:**
```
Дважды кликните на: install-dependencies.bat
```

**Консоль (любая ОС):**
```bash
cd installer
npm install
cd ..
```

### Шаг 2: Запустите установщик

**Windows:**
```
Дважды кликните на: Установить сервер.bat
```

**Консоль (любая ОС):**
```bash
node installer/setup.js
```

---

## 📋 Полная инструкция

1. **Скачайте** репозиторий с GitHub
2. **Распакуйте** в папку (например, `C:\kdz`)
3. **Установите зависимости** (Шаг 1 выше)
4. **Запустите установщик** (Шаг 2 выше)
5. **Следуйте инструкциям** установщика

---

## 🔍 Проверка

Перед запуском убедитесь:

```bash
# Node.js установлен
node --version
# Должна показать: v16.x.x или выше

# npm работает
npm --version
# Должна показать версию
```
