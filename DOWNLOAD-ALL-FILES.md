# Скачать все файлы одной папкой (ZIP-архив)

## ✅ Реализованный функционал

### 📥 Кнопка "Скачать все файлы"

**Расположение:** В модальном окне заявки, в секции вложений.

**Внешний вид:**
```
┌─────────────────────────────────────────────┐
│  📎 Вложения (3)    [📥 Скачать все файлы]  │
├─────────────────────────────────────────────┤
│  [🖼️ photo.jpg]  [📄 doc.pdf]  [🎬 video.mp4]│
│     2.5MB           1.2MB          15MB     │
│     [👁️][⬇️]      [👁️][⬇️]       [👁️][⬇️]   │
└─────────────────────────────────────────────┘
```

---

## 🔧 Как работает:

### 1. Пользователь нажимает кнопку

```javascript
onclick="downloadAllFiles('uuid-заявки')"
```

### 2. JavaScript отправляет запрос

```javascript
POST /api/tickets/:id/files/download-all
```

### 3. Server 2 создаёт ZIP-архив

```javascript
// Получаем все вложения заявки
const attachments = await TicketModel.getAttachments(ticketId);

// Создаём ZIP архив
const archive = archiver('zip', { zlib: { level: 9 } });

// Добавляем файлы с оригинальными именами
for (const attachment of attachments) {
  archive.file(filePath, { name: attachment.file_original_name });
}
```

### 4. Архив скачивается

**Имя файла:**
```
ticket-d184ffd6-files.zip
```

**Содержимое:**
```
ticket-d184ffd6-files.zip
├── photo.jpg          ← Оригинальное имя
├── document.pdf       ← Оригинальное имя
└── presentation.mp4   ← Оригинальное имя
```

## ⚙️ API Endpoint:

**URL:**
```
POST /api/tickets/:id/files/download-all
```

**Headers:**
```
Authorization: Cookie (session)  ← Требуется авторизация
```

**Response:**
```
Content-Type: application/zip
Content-Disposition: attachment; filename="ticket-uuid-files.zip"

[Binary ZIP data]
```

**Ошибки:**

| Код | Сообщение | Причина |
|-----|-----------|---------|
| 404 | "Заявка не найдена" | Неверный ID |
| 404 | "Нет вложений для скачивания" | Пустая заявка |
| 500 | "Ошибка создания архива" | Ошибка сервера |

## 💡 Особенности:

### 1. Потоковая передача

Файлы не загружаются в память, а передаются потоком:
```javascript
archive.pipe(res);  // Прямая передача в HTTP ответ
```

### 2. Максимальное сжатие

```javascript
archiver('zip', { zlib: { level: 9 } });
```

### 3. Оригинальные имена

Файлы сохраняются с оригинальными именами:
```javascript
archive.file(filePath, { name: attachment.file_original_name });
```

### 4. Автоматическое имя архива

```javascript
`ticket-${ticketId.substring(0, 8)}-files.zip`
```

Пример: `ticket-d184ffd6-files.zip`

## ⚠️ Возможные проблемы:

### 1. Ошибка "Нет вложений для скачивания"

**Причина:** У заявки нет файлов.

**Решение:** Создайте заявку с файлами.

### 2. Ошибка "Заявка не найдена"

**Причина:** Неверный ID заявки.

**Решение:** Проверьте ID в URL.

### 3. Архив пустой

**Причина:** Файлы не синхронизировались с Server 1 на Server 2.

**Решение:** Дождитесь синхронизации или запустите вручную.

### 4. Ошибка при создании архива

**Причина:** Файлы удалены или недоступны.

**Решение:** Проверьте наличие файлов в `server2/uploads/`.
