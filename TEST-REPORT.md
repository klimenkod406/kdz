## 🔧 Исправленные ошибки в ходе тестирования

### КРИТИЧЕСКИЕ:

1. **Ошибка в установщике (askDatabaseConfig)**
   - **Проблема:** Неправильная передача serverType между функциями опроса
   - **Решение:** Обновлена сигнатура функции `askDatabaseConfig(serverType)`
   - **Файл:** `installer/setup.js`

2. **SQL-интерполяция в Server 1**
   - **Проблема:** Потенциальная SQL-инъекция в `findNotSent()`
   - **Решение:** Использован параметризованный запрос с `INTERVAL '1 minute' * $1`
   - **Файл:** `server1/src/models/Ticket.js`

3. **Удаление workspaces из package.json**
   - **Проблема:** Workspaces вызывали конфликты при установке
   - **Решение:** Удалены workspaces, каждый сервер устанавливается независимо
   - **Файл:** `package.json`

### НЕКРИТИЧЕСКИЕ:

4. **Кодировка .bat файлов**
   - **Проблема:** Кириллица в .bat вызывала ошибки
   - **Решение:** Заменено на английские сообщения
   - **Файлы:** Все .bat файлы

5. **Зависимость от shared модуля**
   - **Проблема:** После очистки папки shared оставался в package.json
   - **Решение:** Созданы локальные utils.js в каждом сервере
   - **Файлы:** `server1/src/utils.js`, `server2/src/utils.js`

## 🔍 Известные ограничения

1. Серверы должны устанавливаться на разных машинах (или разных портах)
2. Для работы синхронизации Server 1 должен иметь доступ к Server 2
3. Сессии хранятся в PostgreSQL (требуется таблица `session`)
