# Админ-панель - Просмотр вложений

## ✅ Реализованный функционал

### 1. Отображение вложений в заявке

При открытии заявки в модальном окне отображаются все прикреплённые файлы:

- **Иконка файла** - для документов и архивов
- **Миниатюра** - для изображений (preview 150px)
- **Превью видео** - для видеофайлов (загружается первый кадр)

### 2. Lightbox (полноэкранный просмотр)

**Для изображений и видео реализован полноэкранный просмотр:**

- Клик по миниатюре открывает lightbox
- Кнопка "👁️" открывает lightbox
- Навигация между файлами (❮ ❯)
- Закрытие по:
  - Кнопке ×
  - Клавише ESC
  - Клик вне области просмотра

**Горячие клавиши:**
- `ESC` - закрыть lightbox
- `←` - предыдущий файл
- `→` - следующий файл

### 3. Поддерживаемые форматы в lightbox

| Тип | Форматы | Отображение |
|-----|---------|-------------|
| **Изображения** | JPG, PNG, GIF, WebP, BMP | Полноэкранное фото |
| **Видео** | MP4, WebM, MOV, AVI | Видеоплеер с controls |
| **Документы** | PDF, DOC, DOCX и др. | Только иконка (скачивание) |
| **Архивы** | ZIP, RAR, 7Z | Только иконка (скачивание) |

### 4. Скачивание файлов

Каждый файл имеет кнопку скачивания (⬇️):
- Для всех типов файлов
- Работает через API с авторизацией
- Файл скачивается с оригинальным именем

### 5. Информация о файле

Для каждого файла отображается:
- Оригинальное имя файла
- Размер файла (B, KB, MB, GB)
- Тип файла (иконка)
- Количество вложений в заявке

## 🔧 Технические детали

### API endpoints

```
GET /api/tickets/:id
Authorization: Cookie (session)

Ответ:
{
  "ticket": {
    "id": "uuid",
    "employee_name": "...",
    "attachments": [
      {
        "id": 1,
        "file_name": "uuid.jpg",
        "file_original_name": "photo.jpg",
        "file_mime_type": "image/jpeg",
        "file_size": 1024000
      }
    ]
  },
  "comments": [...],
  "history": [...]
}
```

### Просмотр файлов

```
GET /uploads/:filename
(статический middleware, без авторизации для просмотра)
```

### Скачивание файлов

```
GET /api/tickets/:id/files/:filename
Authorization: Cookie (session)
(требуется авторизация)
```

## 🚀 Использование

### 1. Открыть заявку
```javascript
openTicket('uuid-заявки')
```

### 2. Открыть файл в lightbox
```javascript
openLightbox(0) // индекс файла в массиве
```

### 3. Навигация
```javascript
prevAttachment()  // Предыдущий файл
nextAttachment()  // Следующий файл
```

### 4. Закрыть lightbox
```javascript
closeLightbox()
```

---

## ⚠️ Важные замечания

1. **Безопасность**: Скачивание файлов требует авторизации
2. **Производительность**: Видео загружаются с `preload="metadata"` для экономии трафика
3. **Адаптивность**: Сетка вложений адаптируется под размер экрана
4. **Доступность**: Поддержка управления с клавиатуры
