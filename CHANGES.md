# Изменения в системе заявок

## Дата: 2026-04-01

### 📋 Что изменено:

#### 1. **Удалено поле "Телефон"**
- Из формы заявки
- Из базы данных (employee_phone)
- Из моделей данных

#### 2. **Заменено поле "Приоритет" на "Область"**

**Новые значения области:**
- `quality` - Качество продукта
- `cost` - Стоимость
- `sales` - Увеличение продаж
- `disorder` - Беспорядок
- `health` - Здоровье и безопасность
- `productivity` - Производительность
- `overstock` - Чрезмерные запасы
- `environment` - Окружающая среда
