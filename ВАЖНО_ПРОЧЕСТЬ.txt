================================================================================
                    ЕСЛИ УСТАНОВЩИК СРАЗУ ЗАВЕРШАЕТСЯ
================================================================================

ПРОБЛЕМА: Установщик открывается и сразу закрывается без вывода.

ПРИЧИНА: .bat файлы на Windows не поддерживают интерактивный ввод Node.js.

================================================================================
                            РЕШЕНИЕ
================================================================================

ЗАПУСТИТЕ УСТАНОВЩИК НАПРЯМУЮ ЧЕРЕЗ КОНСОЛЬ:

1. Откройте командную строку (Win + R → cmd → Enter)

2. Перейдите в папку проекта:
   
   cd C:\Users\Денис\Desktop\kdz

3. Запустите установщик:
   
   node installer\setup.js

4. Следуйте инструкциям на экране

================================================================================
                    ПОШАГОВАЯ ИНСТРУКЦИЯ
================================================================================

ШАГ 1: Откройте консоль
   - Нажмите Win + R
   - Введите: cmd
   - Нажмите Enter

ШАГ 2: Перейдите в папку
   cd /d C:\Users\Денис\Desktop\kdz

ШАГ 3: Проверьте Node.js
   node --version
   (должна показать версию, например: v24.14.1)

ШАГ 4: Запустите установщик
   node installer\setup.js

ШАГ 5: Выберите тип сервера
   - Используйте стрелки ↑↓ для выбора
   - Нажмите Enter

ШАГ 6: Введите параметры PostgreSQL
   - Хост: localhost (по умолчанию)
   - Порт: 5432 (по умолчанию)
   - Пользователь: postgres (по умолчанию)
   - Пароль: введите ваш пароль

ШАГ 7: Настройте сервер
   - Для Server 1: введите URL Server 2
   - Для Server 2: введите логин/пароль админа

ШАГ 8: Дождитесь завершения
   - Установщик скачает зависимости
   - Создаст базу данных
   - Выполнит миграции
   - Запустит сервер

================================================================================
                    АЛЬТЕРНАТИВНЫЙ СПОСОБ
================================================================================

Если консоль не работает, создайте файл run-installer.cmd:

@echo off
chcp 65001 >nul
cd /d "%~dp0"
cmd /k "node installer\setup.js"

Сохраните как run-installer.cmd и запустите двойным кликом.
Окно консоли останется открытым после завершения.

================================================================================
                    ПРОВЕРКА ПЕРЕД УСТАНОВКОЙ
================================================================================

1. PostgreSQL запущен:
   - Откройте службы (services.msc)
   - Найдите "PostgreSQL"
   - Статус: "Выполняется"

2. Node.js установлен:
   node --version
   (должна быть версия 16+)

3. npm работает:
   npm --version

4. Зависимости установщика:
   cd installer
   npm install

================================================================================
                    КОНТАКТЫ ДЛЯ ПОМОЩИ
================================================================================

Если возникли ошибки, проверьте:

1. Логи установщика (сохраните вывод консоли)
2. Версию Node.js (должна быть 16+)
3. Версию PostgreSQL (должна быть 12+)
4. Параметры подключения к БД
